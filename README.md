#Pyoneiro

##Sobre o Projeto

O Pyoneiro é uma plataforma interativa voltada para o ensino de python para iniciantes

##Objetivo

O projeto tem como objetivo facilitar o início da aprendizagem de Python, oferecendo explicações simples, perguntas e atividades práticas.

#Tecnologias Utilizadas

-Python
-Flask
-HTML
-CSS
-SQLITE
